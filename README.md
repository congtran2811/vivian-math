# Vivian Math

Trình soạn công thức toán (giống MathType) kèm hình 3D và video giải thích bài toán, dành cho giáo viên và học sinh THCS.

## Chạy thử

Cần Node.js 20 trở lên.

```
npm install
npm run dev
```

## Đóng gói

```
npm run dist:win   # bản cài Windows
npm run dist:mac   # bản cài macOS (chạy trên máy Mac)
```

Danh sách chức năng và tiến độ: [docs/chuc-nang.md](docs/chuc-nang.md).
